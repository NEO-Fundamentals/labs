# NEO Fundamentals lab files

Follow-along lab files, diagrams, and scripts for the **NEO Fundamentals** video lessons.

Addresses in every pack are private lab ranges (RFC 1918) only. Names are fictional. These files are for learning, not a real network.

This repository currently publishes the Getting Started lab kit. Additional lesson packs will be added as those videos go public.

## How to use a pack

1. Open the lesson folder, or download its zip.
2. Read that folder's `README.md`.
3. Open the diagram in `diagrams/` if there is one.
4. Follow the written steps in the lesson README.
